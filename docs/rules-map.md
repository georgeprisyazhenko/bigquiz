# Карта связности правил (что обновлять вместе)

Проблема: одно правило живёт прозой в нескольких местах (промпты генератора/судьи,
свод, доки, тесты). Меняешь в одном — забываешь в другом → дрейф. Эта карта делает
протяжку механической: меняешь правило → проходишь ВСЕ зависимые точки по списку.

**Дисциплина:** любое изменение правил генерации/судейства/ревью или промптов —
сначала ПРЕДЛОЖЕНИЕ на аппрув, потом правка по ВСЕМ точкам ниже, потом `npm test`.
Не коммитить молча. (См. память `feedback_pipeline_changes`.)

## Гейты уровня ВОПРОСА (около-спам, вложенные диапазоны, перечисление через «и»)

- **Каноничный код:** `src/content-rules.js` — `validateOptionsHomogeneous` (около-спам ≥2, жёсткий),
  `validateHedgeTell` (хедж ровно в 1 варианте → телеграф верного, мягкое), `validateNumericRanges`
  (вложенные «более N»/«менее N», жёсткий), `validateNumericTell` (верный — единственное не-круглое
  число, мягкое; берёт `correctAnswerIndex`), `validateEnumeration` (запятая→«и», мягкое). Проверяют
  4 варианта ВМЕСТЕ, а не один ответ.
  ⚠ Границу слова `\b` с кириллицей НЕ использовать (`\w` её не включает) — сверять по набору слов.
- Семантические правила (кодом не отловить, только промпт+свод): редкий термин в вопросе
  поясняй; **малоизвестную сущность давай с контекстом** (вид спорта/роль/«где шли Игры»);
  величины в одной единице; дистрактор правдоподобен в контексте; **без бинарных
  «X или Y?»**; **не называй в вопросе сущность, чья идентичность и есть вау**; **варианты без
  подсказки-дискриминатора** (века/размеры в скобках); **варианты по-русски, без англо-фраз**;
  **тема-фит** (ответ не вычисляется из категории; категория соответствует теме);
  **без живых рекордов/переходящих титулов как ответа** (протухают).
  Точки — A.3 (сюрприз/вау), A.5 (дистракторы/бинарность/дискриминатор), A.8 (язык/англо-фразы),
  genPrompt + judgePrompt (`fill-questions`), polish RULES (классы 1ж/1з/3/4).
- Зависимые точки (обновлять вместе):
  - `scripts/lib/review-store.mjs` — `gatesOk` (жёсткие два — блок промоушна; подхватывает и merge-polish).
  - `scripts/merge-gen.mjs` — нарушение жёстких → понижение keep→revise.
  - `scripts/fill-questions.workflow.js` — genPrompt (правила) + judgePrompt (флаги cleanDistractors/naturalLanguage).
  - `scripts/polish.workflow.js` — класс 1(г) (диапазоны) + класс 9 (около-спам + хедж-в-1, «и»; дрейф-фикс: «и» не значимое слово).
  - `src/main.js` — `validateQuestions` (мягкое предупреждение).
  - `src/admin/admin.js` — предупреждения в карточке ревью.
  - `tests/content-rules.test.js` (юниты) + `tests/questions-answers.test.js` (жёсткий гейт по проду).
  - `docs/category-risks.md` (A.5 диапазоны/около, A.8 перечисление).
- **Принцип:** детерминированное (около/диапазоны/запятая) — КОДОМ, не на доверии LLM.

## Правила показа карточки (порядок ответов, картинка)

- **Каноничный код:** `src/card-rules.js` — `orderAnswers`, `imageCandidatePaths`.
- Зависимые: `src/main.js` (игра) и `src/admin/admin.js` (превью) импортируют ОДИН модуль —
  дрейфа нет by design. `docs/GDD_LITE.md` (§4).
- **Превью админки = игра ПО ОТОБРАЖЕНИЮ.** Что нельзя в превью (иначе расхождение с продом):
  - перенос текста — ТОЛЬКО по словам: `hyphens: none`, `overflow-wrap: normal`. НИКОГДА
    `hyphens: auto`/`break-word` (рвёт слово «Папой» → «Па-пой», игра так не делает);
  - шрифт НЕ ужимать (см. лимит длины — не влезает, значит переформулировать);
  - верный ответ на карточке НЕ подсвечен (как в исходном состоянии прода).
  - **Гард:** `tests/admin-preview.test.js` ловит регрессы по исходникам (hyphens:auto,
    ужатие шрифта, отвязку от `card-rules`). Новое правило показа → добавь туда ассерт.
