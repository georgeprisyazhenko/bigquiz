# Дерево категорий BigQuiz (v4)

Дизайн-документ. **Источник данных для приложения — `public/categories.json`**, не этот файл.

## Как используется

- У каждой верхней категории и подкатегории есть стабильный `id` (латиницей) и `name` (русское).
- В `public/questions.json` поле `categories` (1–3) хранит `id` подкатегорий (или `id` верхней категории для общих вопросов, под которые нет подходящей подкатегории).
- Отдельных «тегов» нет: теги вопроса = его категории/подкатегории из этого дерева.
- При переименовании меняем только `name` — вопросы ссылаются на `id` и ничего не теряют.
- Дерево не хранится в коде: и `questions.json`, и `categories.json` тянутся в рантайме из `public/`.

> «Личности» — кросс-секущая ось «по людям». Вопрос может одновременно попасть в предметную ветку и в «Личности» (например, `xx-vek` + `lichnosti-uchyonye`) и показывается в обеих. Поэтому person-подкатегории имеют префикс `lichnosti-`, чтобы их `id` не конфликтовали с предметными (`uchyonye`, `pisateli`, `aktyory` и т.д.).

**Цитаты** реальных людей → `Личности → Цитаты` (`citaty-lichnostey`).

Тон вопросов: «неизбито, даёт узнать новое, но не ультразадротски». Пример: *«Какой металл, кроме ртути, плавится прямо в ладони?»* → Галлий.
