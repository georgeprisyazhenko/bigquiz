# Требования к игре — Яндекс Игры

Источник: https://yandex.ru/dev/games/doc/ru/concepts/requirements  
Дата последнего изменения на сайте: 5 мая 2026 года.

---

## 1. Технические требования

1.1. Встроение SDK Яндекс Игр обязательно  
1.2. Без требования регистрации на сторонних сервисах (допустима авторизация с Яндекс ID)  
1.2.1. Авторизация только после осознанного действия пользователя  
1.2.2. Реализация гостевого входа с сохранением прогресса  
1.3. Звук останавливается при сворачивании страницы  
1.4. Платежи только через SDK Яндекс Игр  
1.5. Реклама вызывается только через SDK  
1.6. Соответствие требованиям указанных в заявке устройств

**1.6.1. Для мобильных устройств:**
- 1.6.1.1. Полноэкранный режим при игре
- 1.6.1.2. Автоматическое отображение клавиатуры при вводе
- 1.6.1.3. Визуальные элементы без деформаций при изменении ориентации
- 1.6.1.5. Управление жестами (может дополняться акселерометром)
- 1.6.1.6. Отсутствие системного плеера в браузерах
- 1.6.1.7. Отсутствие уведомления о WebGL
- 1.6.1.8. Лонгтап не вызывает выделение или контекстное меню

**1.6.2. Для десктопных устройств:**
- 1.6.2.1. Активное поле растягивается до края доступной области
- 1.6.2.2. Соотношение сторон не более 2:1
- 1.6.2.3. Визуальные элементы адаптированы
- 1.6.2.4. Управление клавиатурой или мышью
- 1.6.2.5. Отсутствие системного плеера
- 1.6.2.6. Управление без конфликтующих системных горячих клавиш
- 1.6.2.7. Взаимодействие без выделения контекстного меню

**1.6.3. Для телевизоров:**
- 1.6.3.1. Полноэкранный режим
- 1.6.3.2. Управление стрелками ТВ-пульта (достаточно для полного прохождения)
- 1.6.3.3. Поддержка кнопок Back и ОК
- 1.6.3.4. Отсутствие инап-покупок
- 1.6.3.5. Нет ссылок на другие игры разработчика

1.7. Не используются абсолютные URL на серверы S3 Яндекса  
1.8. Размеры элементов адаптированы для взаимодействия  
1.9. Сохранение изменений сразу после действия или кнопкой сохранения  
1.10. Корректное отображение при изменении размера окна  
- 1.10.1. Масштаб без обрезания элементов
- 1.10.2. Отсутствие браузерной прокрутки
- 1.10.3. Элементы без наложения друг на друга
- 1.10.4. Управление одной рукой на основной сцене

1.11. Указание использования облачных сохранений при заполнении черновика  
1.12. Подключена монетизация Рекламной сети Яндекса  
1.13. Для внутренних покупок:
- 1.13.1. Подключен метод консумирования
- 1.13.2. Название и иконка портальной валюты из SDK
- 1.13.3. Прогресс синхронизирован между устройствами
- 1.13.4. Стоимость в цифрах с указанием валюты
- 1.13.5. Соответствие параметров покупки предложению

1.14. Отсутствие технических ошибок, вылетов, зависаний  
1.15. Завершенный вид, не в процессе разработки  
1.16. Отсутствие модификаций встраиваемых рекламных блоков  
1.18. Отсутствие технических ограничений по URL  
1.19. Инициализация SDK по документации:
- 1.19.1. Строгое соответствие инициализации
- 1.19.2. Вызов `LoadingAPI.ready()` перед началом игры (в течение 90 секунд)
- 1.19.3. Корректное использование `GameplayAPI` методов
- 1.19.4. Правильная обработка событий паузы и возобновления

1.20. Корректный запуск в браузерах и платформах из черновика:
- 1.20.1. Браузеры: Яндекс, Chrome, Firefox, Opera, Safari, Яндекс приложение
- 1.20.2. ОС: Windows Vista+, Mac OS X 10.6+
- 1.20.3. Мобильные ОС: Android 5.0+, iOS 9.0+
- 1.20.4. Android TV

1.21. Размер файлов не превышает 100 МБ в разархивированном виде  
1.22. Файл `index.html` в корне архива; без пробелов и русских символов в именах  
1.23. Запрещено использование интерактивного ИИ (допускается заранее сгенерированный контент)  
1.24. Обновления сохраняют основную концепцию игры

## Детали по ключевым пунктам

### 1.2 — Авторизация

- Пользователи могут играть без регистрации и авторизации
- Допустима только авторизация через Яндекс ID
- Авторизация появляется только после осознанного действия пользователя (нажатия кнопки)
- Всплывающие окна авторизации должны объяснять пользователю выгоду (облачные сохранения, покупки)
- Окно авторизации перестаёт показываться после входа
- Нельзя ограничивать основной функционал игры для неавторизованных пользователей

### 1.3 — Звук вне игры

- При сворачивании браузера, смене вкладки или в меню вкладок звук останавливается
- Допустимо: звук затихает в течение 2 секунд после выхода
- Допустимо: продолжение звука при клике на рекламный баннер
- Исключение: на iOS звук может продолжаться в меню вкладок

### 1.6.3 — Требования для телевизоров

- Управление пультом: стрелки → `ArrowLeft/Up/Right/Down`, OK → `Enter`, Back → обработать вручную
- Back на главном меню: диалог выхода; во время игры: пауза + меню
- SDK: `deviceInfo.type === "tv"` для определения устройства
- Инап-покупки запрещены
- Ссылки на другие игры разработчика запрещены

### 1.9 — Сохранение прогресса

- Рекомендуется: серверы Яндекс Игр через SDK (облачные сохранения)
- Для простых игр без покупок допустимо: localStorage / IndexedDB (теряется при смене устройства/браузера)
- Обязательно для игр, где есть рекорд, достижение или победа
- После обновления страницы пользователь может продолжить игру и не потеряет достижения

### 1.10 — Корректное отображение

- Модерация уменьшает окно браузера на 20% по горизонтали/вертикали/диагонали
- Критичная обрезка (нельзя): кнопки, тексты, значимые элементы, предупреждения о рекламе
- Незначительная обрезка (можно): элемент виден не полностью, но читаем и кликабелен
- Браузерный скроллбар недопустим (проверяется при 80–125% масштаба)
- Swipe-to-refresh должен быть отключён

### 1.12 — Монетизация РСЯ

- По умолчанию игры должны включать монетизацию через РСЯ
- Чтобы отказаться: указать в "Комментарии разработчика" в черновике
- Для получения дохода: подключить покупки (статус "Покупки подключены") **или** полноэкранные/rewarded/стики-баннеры
- Стартовый рекламный блок при загрузке не засчитывается как обязательный

### 1.13 — Инап-покупки

- Метод консумирования должен быть подключён (иначе непроведённые платежи после тестирования блокируют модерацию)
- Название и иконка портальной валюты — из SDK
- Прогресс синхронизируется между устройствами (серверное хранение)
- Цена указывается цифрами с валютой
- Условия покупки соответствуют предложению

### 1.14 — Технические ошибки

Модерация отклоняет игры с:
- Чёрным экраном или только иконкой при загрузке
- Консольными ошибками при инициализации
- Зависанием после смены вкладки
- Техническими текстами в UI (debug-меню, версии SDK)
- Тупиковыми экранами в конце игры без навигации
- Чёрным экраном после рекламы

### 1.15 — Завершённость игры

Бета-версии допустимы только при наличии 10+ минут контента без явных недоработок. Запрещены:
- Зацикленные таймеры, мешающие игровому процессу
- Нечитаемые надписи
- Персонажи, застревающие в текстурах
- Нефункциональные иконки/графические элементы

### 1.19 — Инициализация SDK

- Использовать текущую версию загрузчика
- `LoadingAPI.ready()` вызывать когда меню доступно / игра готова к взаимодействию — в течение 90 секунд
- `GameplayAPI.start()` / `GameplayAPI.stop()` — точно соответствовать состояниям: уровни, меню, магазин, реклама, потеря фокуса браузера
- Проверка через debug-панель (параметр URL `debug-mode=16`): индикатор Game Ready зеленеет, геймпад-иконка меняет цвет

### 2.4 — Игровые механики

Игра должна соответствовать хотя бы одному критерию:
- Соревновательные механики (игрок vs игрок / система)
- Системы прогресса, зависящие от действий игрока
- Чёткие цели (спасти, победить, пройти уровень)
- Условия победы/поражения

**Викторины без счёта и результата — не пройдут модерацию.**

### 2.7 — Возрастной тег

| Рейтинг | Допустимо |
|---------|-----------|
| 0+ | Всё для всех возрастов, без пугающих звуков/изображений |
| 6+ | Стилизованное насилие без вреда персонажам, аварии без смерти |
| 12+ | Схематичное насилие с кровью у фэнтезийных существ, частичная нагота |
| 16+ | Умеренное насилие, кровь, табак/алкоголь, грубый юмор |
| 18+ | Жёсткое насилие, сексуальный контент, азартные игры, эзотерика |

### 2.9 — Продолжительность игры

**Минимум 10 минут основного контента.** Для викторин — **минимум 100 вопросов без дублирования**.

Пути к одобрению:
- Обильный контент (100+ вопросов, 10–20 уровней)
- Реиграбельность (процедурная генерация, рекорды, достижения)
- Комбинация обоих подходов

Отклоняются: 10-секундные раннеры, 3-минутные наборы задач, статичные гонки без соревновательных элементов.

### 2.14 — Автоопределение языка

```javascript
const ysdk = await YaGames.init();
const lang = ysdk.environment.i18n.lang; // 'ru', 'en', 'tr', ...
```

- Автоопределение — при запуске, не в процессе игры
- Обязательно даже для игр с одним языком или без текстов
- Проверка: debug-панель (`debug-mode=16`), индикатор "I18N is used" должен быть зелёным
- SDK mocks → выбор языка → игра открывается на этом языке в новой вкладке
- Допустимо: язык сохраняется в кеше и не переключается после перезагрузки

### 3.6 — Дубликаты игр

Оценивается по 4 параметрам: Механики / Контент / Дизайн / UI/UX. Если 3+ параметра совпадают с другой игрой — дубликат. **Название игры должно быть уникальным в каталоге.**

### 4.4 — Расположение рекламы

- Максимальная задержка от действия пользователя до показа рекламы: **0,33 секунды**
- **Условно-пошаговые игры** (тесты, викторины, пазлы): реклама сразу после действия, без предупреждения
- **Игры в реальном времени, короткие уровни (< 5 мин)**: реклама внутри уровня недопустима
- **Игры в реальном времени, длинные уровни (> 5 мин)**: реклама по таймеру с предупреждением 2 сек
- Игра должна быть на паузе во время предупреждения и показа рекламы

### 5.1.1.2 — Скриншоты в промоматериалах

- Реальный геймплей занимает ≥70% площади изображения
- Допустимо: пространство заполнено поясняющим текстом, персонажами, фонами
- Недопустимо: >30% однотонного фона или градиента

### 5.1.3 — Единое название

Название игры должно быть идентичным во всех материалах и для каждого языка. Допустимы: смена регистра, пунктуация, замена «и» на «&», арабские/римские цифры.

### 8.2.3 — Переводы текстов

**Обязательно переводить:** игровая валюта, кнопки/UI, игровые сообщения (Game Over, Best Score), предупреждения о рекламе, инструкции управления.

**Не требуют перевода:** аббревиатуры (lvl, max), клавиши (Ctrl, Alt), бренды/никнеймы, декоративные эффекты (Boom!), математические символы, жанровые термины (RPG, idle).

**Нельзя:** одновременно отображать текст на двух языках.

### 8.3.4 — Элементы интерфейса в медиа

Запрещены в промоматериалах:
- Статус-бар, индикатор батареи
- Бейджи и рейтинги Яндекс Игр
- Debug-панели, фальшивые бейджи («Лучшее!»)

Допустимы: игровые HUD (шкала здоровья, таймер) только на скриншотах геймплея.

### 8.3.5 — Эротика и дискриминация

Запрещены: порнография, механики раздевания, эротический кликбейт, намёки на секс в названии. Если эротические намёки присутствуют в 2+ материалах одновременно — отказ даже без явных нарушений. Дресс-апы с открытыми нарядами допустимы.

### 8.3.6 — Неприятный контент

Запрещены в промоматериалах (на переднем плане): туалетная тема, реалистичные маргинальные персонажи, графические болезни/травмы, реалистичные трупы, обильная кровь. Допустимы в стилизованном/мультяшном/пиксельном виде на заднем плане.

### 8.4.1 — Ссылки на другие игры

- Только через SDK, только на собственные игры в каталоге
- Только вне активного игрового процесса (меню, перерывы)
- Проверка: debug-панель → SDK mocks → "Game links mock" → клик по ссылке → должна открыться статичная страница

## Глоссарий

- **Лонгтап** — долгое нажатие
- **RV (Rewarded Video)** — видеоблоки с вознаграждением
- **Беджи** — обозначения типа «Акция», «Новая игра», «Промо»
- **More Games** — разделы, ссылки, кнопки с похожими играми
- **debug-mode=16** — параметр URL для включения debug-панели Яндекс Игр SDK

## Примечания

- Время формирования рейтинга новых игр не учитывается (~2 недели с публикации)
- Документы (политика конфиденциальности и т.п.) должны быть встроены текстом в игру, а не открываться в отдельной вкладке
- Прохождение модерации не означает подтверждение соответствия законодательству
- Проверка игр производится на окружениях, приближённых к пользовательским
