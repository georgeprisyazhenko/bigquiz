# DoD — Definition of Done для выпуска BigQuiz на Яндекс Играх

Чеклист всего, что нужно сделать **до отправки на модерацию**. Ссылки `(п. X)` — на
`docs/yandex-games-requirements.md`. Источник SDK — `docs/sdk/html5.md` (обвязка),
реклама/лидерборды — официальный сайт (в наших локальных доках детально не описаны).

## 13. Размещение в Консоли — пошаговый чеклист

Выполняется **один раз** при первой публикации. Подробности — `docs/Размещение.md`.

### Аккаунт и документы

- [ ] Зарегистрировать аккаунт разработчика на Яндекс ID (логин вида `xxx@yandex.ru`)
- [ ] Принять Лицензионное соглашение и Правила размещения игр
- [ ] Выбрать форму сотрудничества (самозанятый → 6% НПД, физ. лицо → НДФЛ, ИП/ООО)
- [ ] Убедиться, что Единая лицензионная схема активна в профиле (нужна для рекламы и покупок)

### Заполнение черновика

- [ ] Нажать «Добавить приложение» → создать черновик с уникальным ID
- [ ] Загрузить ZIP-архив: `index.html` в корне, размер ≤ 100 МБ, без пробелов и кириллицы в именах
- [ ] Указать поддерживаемые платформы (Десктоп / Мобильные / ТВ) и ориентацию
- [ ] Выбрать языки перевода (минимум RU + EN), возрастной рейтинг, не более 2 категорий
- [ ] Включить «Облачные сохранения» (используем `setData`/`setStats`)
- [ ] Заполнить текстовые поля:
  - Название (≤ 50 символов, уникальное в каталоге)
  - Описание для SEO (50–160 символов)
  - Об игре (100–1000 символов)
  - Как играть (100–1000 символов)
- [ ] Загрузить визуальные материалы:
  - Иконка 512×512 PNG (не скриншот из игры)
  - Обложка 800×470 PNG (не скриншот)
  - Скриншоты — минимум 2 для каждой заявленной платформы (≥ 70% реального геймплея)

### Инфраструктура в Консоли

- [ ] Создать лидерборд `best_streak` (сортировка по убыванию, формат `numeric`) — иначе `getEntries` вернёт 404
- [ ] Включить рекламную монетизацию РСЯ (fullscreen + sticky-баннер) через форму РСЯ
- [ ] Добавить внешние хосты в разрешённые (CSP), если используются сторонние ресурсы

### Тестирование перед отправкой

- [ ] Открыть черновик в режиме черновика — убедиться, что игра работает по адресу на yandex.ru
- [ ] Проверить debug-панель (`&debug-mode=16`): Game Ready зелёный, I18N зелёный, Gameplay меняется
- [ ] Протестировать рекламу, авторизацию, лидерборд через моки debug-панели
- [ ] Проверить игру на всех заявленных платформах и браузерах
- [ ] Убедиться в отсутствии крашей, debug-текстов, чёрных экранов после рекламы

### Отправка на модерацию

- [ ] Нажать «Отправить на модерацию» (срок проверки 3–5 рабочих дней)
- [ ] Дождаться результата; при отклонении — исправить нарушения и повторно отправить (cooldown 24 ч после 1-го отказа)
- [ ] При одобрении — убедиться в статусе «Опубликована» (или выбрать момент публикации при отсроченной)

## Порядок работ (вехи)

1. **Плумбинг** (разделы 1–2) ✅ → залить черновик → проверить индикаторы (раздел 11).
2. **Реклама + сохранения** (разделы 3–4) ✅ (код готов; нужно включить в Консоли).
3. **Авторизация + лидерборды** (раздел 5) ✅ (код готов; нужно создать лидерборд в Консоли).
4. **Контент до 100+** (раздел 8) 🚨 — блокер модерации, можно параллельно с кодом.
5. **Мелкие UI-долги** (разделы 6–7): подключить звуковую кнопку, scoreText/scorePopup, логика Блица.
6. **Сборка, UI-требования, публикация** (разделы 9, 10, 12) → финальный черновик → модерация.
