# Yandex Games SDK for Defold — Complete Documentation

Источник: https://yandex.ru/dev/games/doc/ru/sdk/defold/

## 1. Установка (defold/install)

### Installation Steps

Процесс включает четыре основных этапа:

1. **Access Releases**: Перейдите в раздел GitHub Releases для репозитория yandex-games-plugins/defold.

2. **Copy Link**: Найдите и скопируйте URL файла "Source code (.zip)" из последнего release (v1.0.0 на момент показа).

3. **Add Dependency**: Откройте файл конфигурации проекта `game.project` и добавьте скопированную ссылку в список **Dependencies**.

4. **Fetch Libraries**: Используйте опцию меню **Project** → **Fetch Libraries** для загрузки и интеграции плагина в проект.

### Additional Resources

Страница предоставляет ссылки на связанные темы, такие как локализация и другие методы SDK. Для устранения неполадок пользователи направлены в сообщество Telegram для разработчиков, а полный репозиторий доступен на GitHub.

## 2. Локализация (defold/localization)

### Setup

Создайте папку `i18n`, содержащую JSON файлы переводов, организованные по кодам языков (например, `en.json`, `ru.json`).

### Retrieval Methods

- **`i18n.key(key)`** — получает значения переводов
- **`i18n.gui(node_id, key)`** — устанавливает текст узла UI напрямую с переводимым содержимым

### Example Implementation

Руководство демонстрирует регистрацию обратного вызова локализации с помощью `i18n.on()`, который обновляет все текстовые узлы при загрузке переводов.

### Language Switching

Используйте `i18n.set_language(code)` для ручного изменения активного языка. Система автоматически определяет язык пользователя из переменных окружения.

### Auto-Initialization

Модуль i18n "автоматически инициализирует язык, соответствующий языку пользователя из переменных окружения," уменьшая необходимость ручной настройки.

## 3. Запуск игры (defold/game-start)

### Game Ready Method

Основной метод простой:

```lua
ysdk.features.loading_api.ready()
```

Этот метод сигнализирует, что ваша игра завершила загрузку ресурсов и готова к взаимодействию с пользователем.

### Purpose

"Яндекс Игры работают по всему миру, поэтому сбор статистики важен для улучшения скорости загрузки" (Yandex Games operates globally, making performance statistics crucial for improving load speeds).

Сбор этих данных помогает определить размещение инфраструктуры и включает будущие функции, такие как:
- Дополнительное размещение объявлений для дохода разработчика
- Общие экраны загрузки для всех игр
- Скриншоты игр и рецензии для увеличения привлекательности

### Implementation Requirements

Перед вызовом этого метода убедитесь, что:
- Все интерактивные элементы игры полностью операционны
- Экраны загрузки удалены из отображения

## 4. Внутриигровые покупки (defold/in-app-purchases)

### Portal Currency

Платформа использует "Yan" (Ян) в качестве валюты для покупок. Игроки поддерживают единый баланс на всех играх и могут пополнить через банковские карты или рекламные предложения. Как авторизованные, так и гостевые пользователи могут совершать покупки.

### Main Methods

**Create Purchase**
```lua
ysdk.payments.create_purchase(callback, options)
```
Инициирует покупку с опциональными параметрами payload разработчика и защиты от мошенничества (`signed`).

**Get Purchases**
```lua
ysdk.payments.getPurchases(callback, options)
```
"Получает список ранее завершенных транзакций" с опциональной проверкой подписи.

**Get Catalog**
```lua
ysdk.payments.getCatalog(callback)
```
Возвращает доступные товары с ценами, описаниями и изображениями валюты.

**Consume Purchase**
```lua
ysdk.payments.consume_purchase(purchase_token)
```
Помечает расходуемые товары как использованные. **Critical**: Всегда обновляйте статистику игрока перед вызовом этого метода, так как потребление необратимо.

### Prerequisites

**For Russian Residents**: Требуется подписать "Акт приема-передачи неисключительных прав на использование Игры" перед тестированием.

**For Non-Residents**: Отправьте запрос активации на games-partners@yandex-team.ru с деталями игры и юрисдикцией компании.

## 5. Данные игрока (defold/player-data)

### Player Information

Функция `ysdk.player.get_info()` получает детали профиля пользователя, включая статус входа, уникальный идентификатор, имя и фото в нескольких размерах.

### User Authentication

Разработчики могут запустить вход через `ysdk.player.open_auth_dialog()`, когда игроки не авторизованы, с обратным вызовом, подтверждающим успех авторизации.

### Game Data Storage

Три метода обрабатывают сохранение состояния игрока:
- **`ysdk.player.set_data()`** для сложных объектов данных (макс. 200 KB)
- **`ysdk.player.set_stats()`** для числовых значений (макс. 10 KB)
- **`ysdk.player.increment_stats()`** для изменения существующих числовых данных

Соответствующие методы получения (`get_data()`, `get_stats()`) получают сохраненную информацию.

### Cross-Game User IDs

Функция `ysdk.player.get_ids_per_game()` возвращает идентификаторы пользователей во всех играх разработчика, где было дано согласие.

## 6. Оценка игры (defold/game-review)

### Check Review Availability

Метод: `ysdk.feedback.can_review(callback)`

Возвращает возможные причины, по которым обзор недоступен: `NO_AUTH`, `GAME_RATED`, `REVIEW_ALREADY_REQUESTED`, `REVIEW_WAS_REQUESTED` или `UNKNOWN`.

### Request Review

Метод: `ysdk.feedback.request_review(callback)`

Важное ограничение: "Запросить оценку игры можно только один раз за сессию" (review can be requested only once per session).

Возвращает, отправил ли пользователь отзыв или закрыл всплывающее окно.

### Code Example

Документация предоставляет практическую реализацию, показывающую валидацию `can_review()` перед вызовом `request_review()`, с опциональной логикой награды при успешной отправке.

## 7. Переменные окружения (defold/environment)

### Environment Object

Объект окружения содержит четыре основных свойства:

- **app**: Данные игры, включая ID игры
- **browser**: Информация браузера с предпочтением языка в формате ISO 639-1
- **i18n**: Детали локализации с языком интерфейса и доменом верхнего уровня
- **payload**: Опциональный параметр из URL игры (например, значения query string)

### Language Detection

Документация рекомендует использовать **параметр i18n.lang** для определения языка пользователя, так как он представляет "язык интерфейса Яндекс Игр в формате ISO 639-1."

### Top-Level Domain

**параметр tld** указывает, какой вариант домена Яндекса размещает игру (например, "com" для международных версий), что важно для развертываний с несколькими доменами.

## 8. Реклама (defold/adv)

### Three Main Ad Formats

1. **Full-Screen Ads** — `ysdk.adv.show_fullscreen_adv()` отображает объявления, которые полностью покрывают фон приложения

2. **Rewarded Video** — `ysdk.adv.show_rewarded_video()` показывает видео объявления, где пользователи получают награды при завершении

3. **Sticky Banner** — постоянные баннеры, настроенные через Developer Console с опциями управления API

### Implementation Recommendations

Руководство рекомендует разработчикам:
- Размещать объявления так, чтобы пользователи понимали, что это не геймплей ("перед началом игры, при переходе на следующий уровень, после проигрыша")
- Избегать срабатывания объявлений во время активного геймплея для предотвращения непреднамеренных кликов
- Отметить, что частота rewarded video неограниченна, а частота полноэкранных объявлений управляется платформой

### Callback Functions

Каждый тип объявления поддерживает опциональные обратные вызовы:
- **`on_close`** — срабатывает при закрытии объявления
- **`on_open`** — срабатывает при отображении объявления
- **`on_error`** — возвращает объекты ошибок
- **`on_rewarded`** — (только rewarded video) подтверждает, что зритель просмотрел содержимое

## 9. События (defold/events)

### Event Methods

SDK предоставляет два основных метода для управления событиями:

- **`on_event()`** — регистрирует слушатели для конкретных событий
- **`dispatch_event()`** — программно запускает события

### HISTORY_BACK Event

"Чтобы отследить нажатие на кнопку **Back**, используйте метод" (To track back button presses, use the method):

```lua
ysdk.on_event("HISTORY_BACK", function (self)
    -- Custom dialog implementation
end)
```

**Note:** Это событие функционирует только при запуске игры на телевизионных устройствах.

### EXIT Event

Когда пользователи подтверждают выход из игры через пользовательский диалог, отправьте событие выхода:

```lua
ysdk.dispatch_event("EXIT")
```

## 10. Лидерборды (defold/leaderboard)

### Main Leaderboard Operations

Руководство объясняет четыре основные операции с лидербордами:

1. **Getting leaderboard description** — получить метаданные с помощью `ysdk.leaderboards.get_description()`, которая возвращает свойства, такие как имя, название и правила сортировки.

2. **Setting new scores** — используйте `ysdk.leaderboards.set_score()` для записи результатов игрока. "Запрос можно отправлять не чаще, чем раз в секунду" (requests limited to once per second).

3. **Fetching player ranking** — вызовите `ysdk.leaderboards.get_player_entry()` для получения позиции авторизованного пользователя и деталей очков.

4. **Displaying entries** — используйте `ysdk.leaderboards.get_entries()` с опциональными параметрами для показа топ-игроков или рейтингов вокруг текущего пользователя.

### Requirements

Игроки должны быть авторизованы, а лидерборды должны быть предварительно созданы в консоли разработчика с совпадающими техническими названиями, чтобы избежать ошибок 404.

## 11. Ярлык на рабочий стол (defold/shortcut)

### Availability Check

Метод `ysdk.shortcut.can_show_prompt()` перед отображением опции ярлыка проверяет, может ли она быть добавлена на устройство пользователя.

### Prompt Display

Метод `ysdk.shortcut.show_prompt()` отображает нативный диалог для добавления ярлыка игры на рабочий стол. Реализационное примечание указывает: "При первом вызове создается ярлык на каталог Яндекс Игр. Если такой уже существует, создается ярлык, связывающий напрямую с игрой."

### Code Examples

Документация предоставляет примеры кода Lua, показывающие оба метода проверки и запроса с обработкой обратных вызовов для ответов пользователя.

## 12. Другие объекты и параметры SDK (defold/params)

### Screen Object

Конфигурация экрана включает управление полноэкранным режимом и контроль ориентации. Как указано, "Яндекс Игры могут автоматически запускаться в полноэкранном режиме" (Yandex Games may automatically launch in fullscreen mode), хотя ограничения браузера обычно требуют взаимодействия пользователя для переключения режима.

### Clipboard Object

Включает функцию записи текстовых строк в буфер обмена пользователя через метод `write_text()`.

### Device Information Object

Получает классификацию устройства через `device_info()`, возвращая данные о том, является ли устройство мобильным, настольным, планшетным или основанным на ТВ, а также соответствующие boolean флаги.
