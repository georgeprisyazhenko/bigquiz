# Yandex Games SDK for Unity — Complete Documentation

Источник: https://yandex.ru/dev/games/doc/ru/sdk/unity/  
Plugin Your Games 2.0 — свободный, open-source плагин для публикации Unity игр на платформе Яндекс Игр.

---

## 1. Знакомство и установка (unity/install)

### Key Features

Плагин позволяет разработчикам:
- Интегрировать лидерборды
- Добавить монетизацию через рекламу и внутриигровые покупки
- Тестировать проекты с функциональностью SDK Яндекс Игр
- Включить облачные системы сохранения

### Modular Architecture

"Каждая функция упакована в отдельный модуль" (each feature is packaged as a separate module), обеспечивая, что неиспользуемый код не увеличивает размер финальной сборки.

### Learning Resources

Страница ссылается на серию из 10 видеоуроков, охватывающих:
- Реклама
- Переменные окружения, авторизация и локализация
- Облачные сохранения и управление данными
- Лидерборды
- Внутриигровые покупки
- Аналитика
- Серверное время и ярлыки приложений
- Флаги функций и ссылки на другие игры
- Оптимизация и конфигурация

### Community Support

Разработчики могут получить доступ к обновлениям и помощи через официальный канал Telegram и группу чата для Plugin YG2.

## 2. Реклама (unity/advertisement)

### Three Ad Types

**Fullscreen ads** - показываются во время логических пауз в игре

**Rewarded video ads** - пользователи смотрят объявления в обмен на награды

**Sticky banners** - отображаются вдоль краёв экрана во время игры

### Important Requirements

Реализация монетизации через объявления является обязательной согласно требованию 1.12, но реклама от третьих сторон запрещена (требование 1.16). Показ объявлений регулируется разделом 4 требований к игре.

## 3. Переменные окружения, авторизация, локализация (unity/env-auth-lang)

### Core Modules

**Environment Variables**: Предоставляет доступ к данным платформы, включая информацию об устройстве пользователя, язык, ОС и тип браузера.

**Authorization**: Включает интеграцию лидербордов и обработку платежей. Важно, что игры должны оставаться доступными без аутентификации (согласно требованиям 1.2). Этот модуль получает данные пользователя, такие как прозвища и аватары.

**Localization**: 
- Автоматически регулирует язык игры на основе определения платформой
- Игры должны поддерживать как минимум один язык, выбранный при заполнении черновика
- Рекомендуется добавление локализаций для русского, английского и турецкого языков
- Поддерживает автоматический перевод через Google Translate

### Important Requirements

Игры должны быть "переведена хотя бы на один выбранный при заполнении черновика язык" (translated into at least one language selected when completing the draft).

## 4. Облачные сохранения (unity/progress-saving)

### Purpose of Cloud Saves

Сохранение игрового прогресса создает "удобный и разнообразный игровой опыт." Разработчики могут хранить данные состояния игры (пройденные уровни, очки опыта, внутриигровые покупки и т.д.) на серверах Яндекса или собственном backend.

### When Cloud Saves Are Required

- Игроки должны продолжить после обновления страницы без потери достижений
- Игры с нарративной прогрессией, уровневым продвижением или функциональностью лидербордов
- Бесконечные игры (согласно требованию 2.6)

### Required Declaration

Разработчики, использующие облачные сохранения, должны "указать это в черновике" согласно требованию 1.11.

## 5. Лидерборды (unity/leaderboards)

### Overview

"Таблицы лидеров мотивируют пользователей проводить в игре больше времени и добавляют элемент соперничества" (leaderboards motivate users to spend more time in games and add competitive elements).

### Implementation Requirements

Для включения функциональности лидербордов разработчики должны:
- Импортировать модули Leaderboards и Authorization
- Настроить лидербордов в Developer Console

---

## 6. Внутриигровые покупки (unity/inaps)

### Key Information

Документация описывает интеграцию внутриигровых покупок для Unity игр на платформе Яндекс.Игры. Подобная функциональность "увеличивают доход от игры и возвращаемость игроков."

### Implementation Requirements

Для корректной работы покупок необходимо:

1. **Code Integration** — подключение функциональности в исходном коде приложения
2. **Console Setup** — конфигурация параметров через административный интерфейс платформы
3. **Save System** — обязательное использование модуля сохранения прогресса (рекомендуется Player Stats)

## 7. Метрики (unity/metrics)

### Overview

"Метрики — это показатели, которые позволяют отслеживать ключевые события" (Metrics are indicators that track key events), такие как ежедневные показы объявлений или внутриигровые покупки.

### Purpose

Метрики помогают разработчикам понять, как изменения в геймплее влияют на поведение пользователей путем сравнения производительности до и после модификаций.

### Available Metrics

Консоль Яндекс Игр отображает метрики монетизации, коэффициенты конверсии и различные другие показатели производительности. Для отслеживания дополнительных пользовательских событий разработчики должны создать счётчики с помощью Яндекс Метрики и интегрировать их через плагин.

## 8. Серверное время, оценка игры, ярлыки (unity/other)

### Server Time

Помогает разработчикам:
- "Защита от читерства": предотвращает манипуляцию геймплей путём изменения времени устройства
- Включение надежных игровых событий, таких как ежедневные бонусы, сезонные активности и квесты

### Game Reviews

Позволяет запросить оценки или комментарии игроков через нативный диалог. Приглашение появляется только для авторизованных пользователей, которые ранее не оценивали игру.

### Desktop Shortcut

Позволяет предложить пользователям опцию добавить ссылку на игру на домашний экран через нативный диалог.

## 9. Флаги и ссылки на другие игры (unity/flags-links)

### Flags (Remote Configuration)

Флаги позволяют разработчикам "в любое время менять данные игры, что упрощает настройку баланса в игре" — включая такие изменения как статистику персонажей или стоимость улучшений, без развертывания новых сборок.

### Game Links

Помогают расширить аудиторию путем интеграции списков других доступных игр. Отображение отдельных игр может быть контролируемо удаленно с использованием флагов и префабов.

### Key Features

- Возможность удаленного экспериментирования, где пользователи распределяются в группы
- Интеграция через префабы (templates игровых объектов Unity)
- Централизованное управление через флаги для видимости игры
