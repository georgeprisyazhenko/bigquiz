## Аналитика

> URL: https://yandex.ru/dev/games/doc/ru/concepts/analytics

Аналитика помогает принимать обоснованные решения по развитию игры. Консоль Яндекс Игр содержит встроенные инструменты для анализа метрик после публикации игры и отслеживания ключевых показателей: от количества игроков и времени в игре до дохода от монетизации.

Шесть основных инструментов аналитики:
1. **Общий доход** — сводная информация по монетизации
2. **Панель управления** — основные метрики и алерты
3. **Метрики** — статистика по различным показателям
4. **Метрики покупок** — анализ in-app покупок
5. **Отзывы** — обратная связь от пользователей
6. **Яндекс Метрика** — детальный веб-анализ

Виджеты метрик имеют единообразный интерфейс с подсказками. Многие виджеты поддерживают фильтры: по периоду, типу устройства, стране или конкретному продукту.

> Данные обновляются с задержкой 2–3 дня (метрики РСЯ — день в день).

Для проверки гипотез рекомендуется использовать:
- **А/В-тест иконок** — для оптимизации привлечения из каталога
- **А/В-тесты версий** — для тестирования изменений в игре
- **Эксперименты с флагами** — для изменения конфигурации без обновления

### Общий доход

> URL: https://yandex.ru/dev/games/doc/ru/console/total-income

Раздел для просмотра суммарного дохода по всем играм. Доступен **только для владельца игры** и разработчиков с ролью «Просмотр дохода».

**Отображаемые данные:**
- Доход по каждой игре в отдельном столбце
- Сумма общего дохода по всем проектам внизу

**Выбор периода:**
- Относительные периоды: 7, 14, 30, 60 дней
- Календарные периоды: последние шесть месяцев

**Экспорт данных:**
CSV-файл содержит:
- Общий доход
- Разбивку по играм
- Разбивку по источникам монетизации (реклама и внутриигровые покупки)

> Данные не включают налоговые сборы и не являются официальным предложением или договором.

### Панель управления

> URL: https://yandex.ru/dev/games/doc/ru/console/control-panel

Вкладка в Консоли Яндекс Игр, где разработчики могут просмотреть основную информацию по метрикам игры и обновлениям её статуса.

**Как перейти:**
1. Войти в Консоль с аккаунтом разработчика
2. Нажать на «Игры» в левом верхнем углу
3. Выбрать нужную игру из списка

**Три основных раздела:**

**Алерты** — содержат важную информацию о статусе игры:
- Снятие игры с каталога
- Отсутствие стики-баннеров
- Падение ключевых показателей

**Важные цифры** — ключевые метрики:
- Количество уникальных игроков в день (DAU)
- Суммарное количество минут в день, которое игроки провели в игре

**Диаграммы** — визуальное распределение:
- По географическому расположению игроков
- По типам устройств: компьютеры, мобильные, телевизоры

### Метрики

> URL: https://yandex.ru/dev/games/doc/ru/concepts/metric

Вкладка «Метрики» в Консоли Яндекс Игр. Просмотр метрик дохода доступен только владельцу и разработчикам с ролью «Просмотр дохода».

**Продуктовые метрики:**
- Рейтинг игры — отражает вовлечённость пользователей (формируется ~через 2 недели после публикации)
- Время играния
- Количество игроков
- Среднее время на одного игрока

**Конверсии:**
- CTR иконок и обложек в рекомендациях
- Конверсия в игровые сессии
- Время играния по длительностям: 1, 3, 5, 10, 30 минут

**Возвращаемость игроков (Retention):**
- День 1, 3, 7, 14
- Вторая неделя
- Второй месяц после первого запуска

**Метрики монетизации:**
- Дневной доход
- ARPDAU (средний доход на дневного активного пользователя)
- Доля платящих игроков
- Количество in-app покупок
- Метрики рекламных блоков: sticky, interstitial, rewarded

**Технические метрики:**
- **Game Ready** — готовность игры к запуску
- **Time To Interactive (TTI)** — время загрузки

Все метрики доступны с возможностью фильтрации по периоду, типу устройства и стране.

### Метрики покупок

> URL: https://yandex.ru/dev/games/doc/ru/console/purchase-metrics

Инструменты для анализа покупок в игре. Доступны владельцам игр и разработчикам с ролью «Просмотр дохода».

Позволяет отследить: как платят игроки, структуру выручки и популярные товары.

**Доступные фильтры:**
- Период
- Разбиение по времени
- Тип устройства
- Страна
- Товары (инапы)

**Ключевые метрики:**
- Доход в рублях
- ARPPU (средняя выручка на платящего игрока)
- Количество платящих пользователей
- Структура платежей
- Список купленных товаров с полной статистикой

**Вкладки анализа:**
- **Метрики** — визуальные данные и диаграммы
- **Отчёт** — ежедневные показатели
- **Транзакции** — информация о каждом платеже с деталями

### Отзывы

> URL: https://yandex.ru/dev/games/doc/ru/console/reviews

**Оценка игроков:**
Пользователи могут оставлять отзывы через каталог или Консоль разработчика. При достижении **10 и более отзывов** формируется «Оценка игроков» в виде звёздного рейтинга.

**Сроки публикации:**
- Новые игры ожидают публикации отзывов **1–1,5 месяца** (время регистрации в системе)
- Существующие игры — около **недели** модерации

**Ответы на отзывы:**
- Оставлять официальные ответы могут владельцы и администраторы
- Ответы появляются через несколько дней после модерации
- Ответы должны соответствовать правилам публикации отзывов

**FAQ:**
- Отзывы, нарушающие правила, можно пожаловаться — модерация проводится независимо от разработчика
- Поддерживаются отзывы от международных игроков
- Контактную информацию в ответах использовать не рекомендуется

### Яндекс Метрика

> URL: https://yandex.ru/dev/games/doc/ru/concepts/yandex-metrica

Встроенные метрики Консоли работают автоматически. Для детального анализа можно подключить счётчик Яндекс Метрики.

**Возможности Яндекс Метрики:**
- Настраивать пользовательские цели и события
- Строить воронки конверсии
- Анализировать поведение пользователей
- Создавать сегменты аудитории

**Подключение счётчика:**
1. Открыть Яндекс Метрику
2. Создать счётчик (снять отметку о принятии данных только с указанных адресов)
3. Добавить счётчик в игру через Настройки → Счётчик
4. Обновить версию игры в Консоли

**Настройка пользовательской цели:**
1. В Яндекс Метрике выбрать счётчик
2. Перейти на вкладку Цели → Добавить цель
3. Указать название и выбрать тип «JavaScript-событие»
4. Скопировать код и вставить в файлы игры
5. Обновить версию игры

## Развитие игры

### Выпуск обновлений

> URL: https://yandex.ru/dev/games/doc/ru/console/update-game

После публикации игры можно редактировать её параметры и исходный код. При внесении изменений игра заново проходит модерацию; ранее загруженная версия остаётся доступной в каталоге во время проверки.

**Пошаговый процесс:**
1. Проверить соответствие требованиям
2. Войти в Консоль с аккаунтом разработчика
3. Перейти в раздел «Игры»
4. Выбрать нужную игру
5. Создать или открыть черновик
6. Отредактировать данные и загрузить новый архив
7. Отправить на модерацию

**Модерация:**
- Обычно занимает **3–5 рабочих дней**
- Одновременно может проходить только одна модерация (черновика или тестов)

**Результаты модерации:**
- При одобрении: статус «Опубликовано» или «Проверен» (при отсроченной публикации)
- При отклонении: разработчик получает уведомление с причинами

---

### А/В-тесты версий

> URL: https://yandex.ru/dev/games/doc/ru/console/ab-builds

A/B-тестирование версий позволяет проверить, как изменения в игре влияют на поведение реальных игроков до выпуска полноценного обновления.

> Тест можно запустить **только для уже опубликованных игр**.

**4 этапа:**

**Этап 1: Подготовка**
- Загрузить экспериментальную сборку
- Описать вносимые изменения
- Указать целевую аудиторию: 10%, 20%, 50% или 100%
- Указать длительность теста: 7, 14, 21 или 28 дней

**Этап 2: Модерация**
- Проверка соответствия требованиям: 3–5 дней
- При отклонении можно повторно отправить исправленную версию (с растущим интервалом ожидания)

**Этап 3: Запуск**
- После одобрения эксперимент начинается
- Отслеживаемые метрики: время в игре, конверсия сессий, показы объявлений, доход, покупки

**Этап 4: Итоги**
- По завершении тестирования решение: опубликовать новую версию или остановить эксперимент
- Для надёжных результатов требуется минимум **неделя** сбора данных

### Флаги

> URL: https://yandex.ru/dev/games/doc/ru/config

Удалённая конфигурация (Remote Config) на базе **Varioqub** — позволяет управлять настройками игры без обновления архива. Изменения применяются в течение нескольких секунд и не требуют дополнительных проверок.

**Примеры использования:**
- Балансировка параметров и экономики
- Адаптация под пользователей разных стран
- Управление сезонными предложениями
- Настройка размера вознаграждения за rewarded video
- Оптимизация качества графики по устройствам
- Постепенное внедрение новых функций

**Ограничения:**
- До **100 флагов**
- Каждый флаг — одно значение по умолчанию и два условных значения

**Три шага для запуска:**
1. Создать конфигурацию в Консоли с параметрами (языки, регионы, платформы)
2. Опубликовать конфигурацию
3. Активировать через метод `ysdk.getFlags()` в SDK

### Эксперименты

> URL: https://yandex.ru/dev/games/doc/ru/console/vq-test

Система A/B-тестирования на базе флагов для проверки гипотез о влиянии изменений на поведение игроков. Позволяет разбить аудиторию на группы и показать каждой группе различные варианты конфигурации.

**5 ключевых этапов создания эксперимента:**
1. **Название и описание** — формулировка гипотезы
2. **Условия** — определение целевой аудитории, периода и доли участников
3. **Метрики** — выбор показателей (время игры, конверсия, доход и т.д.)
4. **Варианты** — настройка тестовых версий с использованием флагов
5. **Запуск** — инициирование эксперимента

**Анализ результатов:**
- Статистический отчёт с графиками и таблицами
- Используется критерий **Mann-Whitney U test** для определения значимости
- Успешные варианты можно добавить в основную конфигурацию

**Ограничения:**
- Максимум **2 эксперимента** одновременно
- Максимальная длительность — **30 дней**
- Максимум **26 вариантов**

### Лидерборды

> URL: https://yandex.ru/dev/games/doc/ru/concepts/leaderboards.html

Лидерборд — инструмент, позволяющий показывать игрокам персонализированные таблицы рейтинга с результатами лучших игроков и позицией авторизованного пользователя на странице игры.

**Зачем нужны лидерборды:**
- Улучшают метрики приложения: трафик и удержание пользователей
- Повышают шансы попасть в раздел «Наш выбор»
- Делают игру более заметной в каталоге

**Два подхода к реализации:**
1. **Через Яндекс Games SDK** — отслеживает только авторизованных пользователей
2. **Кастомная реализация в коде игры** — отслеживает всех пользователей независимо от авторизации

**Создание лидерборда:**
1. Добавить код SDK в исходные файлы игры
2. Войти в Консоль разработчика
3. Выбрать игру
4. Перейти на вкладку «Лидерборды»
5. Заполнить необходимые поля

**Поля настройки:**
- **Техническое имя** — используется для взаимодействия с SDK
- **Отображаемое имя** — локализованное для разных языков
- **Основной лидерборд** — только один может быть назначен основным
- **Тип** — «numeric» (числа) или «time» (миллисекунды)
- **Направление сортировки** — по убыванию (высшие очки первые) или по возрастанию
- **Точность десятичных** — количество знаков после запятой

**Редактирование:**
Существующие лидерборды можно изменить через кнопку «Изменить лидерборд». Редактируемые поля: техническое имя, отображаемое имя, статус основного.

## Привлечение игроков

> URL: https://yandex.ru/dev/games/doc/ru/concepts/promotion

Продвижение помогает привлечь в игру больше пользователей. В результате увеличивается получаемый доход.

**Способы продвижения:**
1. **Платное продвижение** — размещение в каталоге и на страницах других игр
2. **Органическое продвижение** — через ранжирование и фичеринг
3. **A/B-тест иконок** — для оптимизации обложек
4. **Промоакции** — события для привлечения аудитории

**Рекомендации:**
- Определить целевую аудиторию
- Подготовить качественные промоматериалы
- Добавить локализацию на несколько языков
- Адаптировать игры для мобильных устройств

---

### Платное продвижение

> URL: https://yandex.ru/dev/games/doc/ru/concepts/start-screen

Платное продвижение — размещение проектов в каталоге и на страницах других игр, размещённых на Яндекс Играх. Запускается через **Яндекс Директ**.

**4 этапа запуска:**
1. Авторизоваться в Яндекс Директе или зарегистрировать новый аккаунт
2. Включить доступ к API для интеграции
3. Предоставить доступ к Директу из Консоли разработчика
4. Настроить кампанию с выбором бюджета и стратегии

**Стратегии кампании:**
- **«Максимум целевых действий»** — фокус на вовлечённых игроков
- **«Максимум переходов»** — максимизация охвата аудитории

**Результаты:**
После запуска игра отображается в:
- «Рекомендованных играх» на главной странице Яндекс Игр
- Блоке «Похожие игры»

**Статистика:** Метрики отслеживаются в Консоли разработчика, Яндекс Директе и Яндекс Метрике.

**Бюджет:**
- Минимальный еженедельный бюджет: **300 рублей**
- Рекомендуемый размер: **7 000 рублей**

---

### Органическое продвижение

> URL: https://yandex.ru/dev/games/doc/ru/concepts/ranking-and-featuring

**Ранжирование** — упорядочивание игр в каталоге на основе алгоритмов машинного обучения, анализирующих метрики качества, рейтинги и данные о сессиях пользователей.

**Фичеринг** — попадание в тематические подборки. Готовность игры оценивается через «Заполненность карточки», которая отслеживает наличие описаний, изображений, видео и других необходимых материалов.

**Разделы каталога:**

**«Новые»** — раздел для недавно опубликованных игр:
- Игра находится там неделю
- После этого распределение зависит от рекомендательной системы на основе пользовательских метрик

**«Популярные»** — вручную отобранные перспективные игры с хорошими показателями:
- Поддержка мобильных устройств
- Переводы на несколько языков
- Качественные промоматериалы

**Как работает рекомендательная система:**
Система изучает новую игру, показывая её разным пользователям, оценивает характеристики по метрикам и может определить качество игры примерно за неделю.

---

### А/В-тест иконок

> URL: https://yandex.ru/dev/games/doc/ru/concepts/ab-test

Иконка и обложка влияют на привлечение игроков из каталога. A/B-тест разделяет пользователей поровну между контрольной и экспериментальной группами.

**Типы аудитории для тестирования:**
- Вся аудитория каталога
- Русскоязычная аудитория
- Международная аудитория

**4 этапа запуска:**
1. Подготовить промоматериалы согласно требованиям
2. Создать заявку в консоли
3. Загрузить файлы (с опциональным применением для всех языков)
4. Отправить на модерацию

**Отслеживаемые метрики:**
- CTR иконки/обложки
- Конверсия в игровую сессию
- DAU
- Время играния
- Доход
- In-app покупки

**Принятие решения:**
- Минимум **7 дней** тестирования для статистической значимости

**FAQ:**
- Приоритет имеют продуктовые метрики (время и конверсия)
- Одновременное обновление игры и тест иконок несовместимы
- Незакрашенные метрики означают недостаточно данных

### Промоакции

> URL: https://yandex.ru/dev/games/doc/ru/console/promo-and-discounts

Промоакции — события, направленные на увеличение числа пользователей, роста покупок и развития игрового сообщества. Появляются в разделе «Скидки и акции» каталога Яндекс Игр.

Разработчикам рекомендуется **регулярно добавлять в игру промоакции** для привлечения игроков.

#### Общие требования к промоакциям

> URL: https://yandex.ru/dev/games/doc/ru/console/promo-rules

Семь ключевых правил:

1. **Соответствие законодательству** — содержимое событий не должно нарушать законодательство РФ и содержать запрещённые материалы
2. **Публикация игры — предусловие** — промоакции принимаются только для опубликованных в каталоге игр
3. **Неперекрывающиеся периоды** — одновременно нельзя проводить несколько акций одной игры с пересекающимися сроками
4. **Сохранение архива** — архив событий хранить в неизменном виде для возможности проведения новых акций
5. **Разнообразие и интервалы** — чередовать различные типы акций, избегая чрезмерной частоты
6. **Модерационная проверка** — все события проходят проверку; контакты в профиле должны быть актуальны
7. **Предварительное планирование** — разработку билдов начинать заблаговременно с учётом времени модерации

#### Правила оформления промоакций

> URL: https://yandex.ru/dev/games/doc/ru/console/promo-event

**Название:**
- Характерное и уникальное
- Максимум **46 символов** включая пунктуацию
- Без призывов к действию
- ✅ Правильно: «Осенний сезон тыкв в Играляндии»
- ❌ Неправильно: «УЧАСТВУЙТЕ!!! Нереальные скидки!!!»

**Описание:**
- Максимум **250 символов** включая пунктуацию
- Отражает суть события и условия участия (сроки, размер скидок, условия)
- Без общих фраз и чрезмерной пунктуации

**Обложка (баннер):**
- Формат: **PNG**
- Размер: **928 × 540 пикселей**
- Уникальная для каждого тематического события
- Чёткий текст, без перегрузки информацией
- Визуализирует суть промоакции

## Командная работа

> URL: https://yandex.ru/dev/games/doc/ru/console/teamwork

Система управления доступом команды к игровому проекту.

> «Доступ выдаётся к конкретным приложениям, а управлять им может только владелец игры».

**Финансовые метрики** доступны исключительно владельцу и разработчикам с особой ролью просмотра дохода.

**6 ролей:**

| Роль | Описание |
|------|----------|
| Администратор | Широкий доступ к управлению игрой |
| Разработчик | Работа с исходным кодом и настройками |
| Аналитик | Просмотр метрик и аналитических данных |
| Поддержка | Работа с отзывами и обращениями |
| Менеджер приложений | Управление игровыми материалами |
| Менеджер рекламы | Настройка рекламной монетизации |

**Управление пользователями:**

**Добавление:**
1. Перейти в «Пользователи и доступ»
2. Ввести логин Яндекс ID
3. Выбрать роли и приложения

**Редактирование:**
1. Открыть профиль пользователя
2. Изменить набор ролей и разрешений

**Удаление:**
1. Выбрать пользователя
2. Нажать «Удалить»

## Языки и домены

> URL: https://yandex.ru/dev/games/doc/ru/concepts/languages-and-domains

**Поддерживаемые языки:**
Платформа поддерживает **41 язык** в формате ISO 639-1, включая русский, турецкий, английский, японский, китайский и многие европейские языки.

**Рекомендуемый минимальный набор локализации:**
Русский, турецкий и английский — для максимального охвата аудитории.

**Резервные языки:**
- При отсутствии нужного языка используется **русский** — для группы постсоветских стран
- **Английский** — для остальных регионов

**Поддерживаемые домены:**
16 региональных доменов Яндекса (yandex.ru, yandex.com, yandex.kz и др.) для разных стран.

**AI-описания:**
Автоматическая генерация описаний игр на разных языках на основе английского текста с помощью нейросети.
- Доступна только на этапе **черновика** игры
- Помогает привлечь больше органического трафика от иностранных пользователей

**CSP-требования:**
Для игр на собственных доменах необходимо добавить все перечисленные домены Яндекса в **Content Security Policy**.

## Удаление и восстановление игры

> URL: https://yandex.ru/dev/games/doc/ru/console/delete-game

### Удаление из каталога

Разработчик может исключить опубликованную игру из каталога через Консоль (вкладка «Опубликовано»).

**Условия:**
- Не должно быть активных черновиков
- Не должно быть активных A/B-тестов

После удаления из каталога версия перемещается в раздел «Черновик».

### Полное удаление

После снятия с публикации черновик можно окончательно удалить через меню трёх точек.

> **Внимание:** Процесс **необратим** — восстановление невозможно. Пустая карточка приложения остаётся в истории.
>
> Все материалы на вкладке «Черновик» хранятся на сервере Яндекса бессрочно, но при удалении черновика они удаляются безвозвратно.

### Восстановление

**Если разработчик самостоятельно удалил игру:**
Можно отправить черновик на повторную модерацию.

**Если администраторы Яндекс Игр удалили игру:**
Необходимо подать запрос восстановления через форму обратной связи, указав в сообщении характер запроса.
